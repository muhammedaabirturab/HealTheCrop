# Knowledge base sources

`cv/data/disease_knowledge_base.json` is generated by
`cv/scripts/build_knowledge_base.py` from the raw extractions in this
directory. It is **not** hand-authored — the pesticide names, dosages,
biological control agents, and symptom descriptions in the crop-specific
entries are pulled from official government agricultural documents, not
written from general LLM knowledge.

## Primary source: NIPHM IPM Packages

The [National Institute of Plant Health Management](https://niphm.gov.in)
(NIPHM), under the Directorate of Plant Protection, Quarantine & Storage,
Ministry of Agriculture & Farmers Welfare, Government of India, publishes an
"AESA (Agro-Ecosystem Analysis) based Integrated Pest Management Package" for
87 crops at `https://niphm.gov.in/IPMPackages/<CropName>.pdf`. Each package
documents, per crop: major national/regional insect pests, diseases, and
nematodes; economic threshold levels; cultural, mechanical, and biological
control practices; and CIBRC-approved chemical control recommendations with
exact product names, formulations, and application rates.

### Extraction method

The site blocks directory listing of `/IPMPackages/` (403), so individual PDF
URLs were found via web search rather than by browsing an index, until an
actual crop index page was located at `niphm.gov.in/IPMPackages.html` listing
all 87 crop filenames. For each crop:

1. Download the PDF.
2. Extract text with `pypdf` (`PdfReader(...).pages[i].extract_text()`) —
   `pdftoppm`/poppler wasn't available in this environment, so `pypdf` was
   used instead of page-image rendering.
3. Read the extracted text and mine, per pest/disease: common + scientific
   name, category, symptoms, cultural control, biological control agents,
   and chemical control with exact product names/dosages as stated in the
   document. Where a document gives no chemical recommendation for an item
   (several rely purely on cultural/biological control), that's recorded
   honestly rather than invented.
4. Save the structured result as `niphm_<crop-or-batch>.json` in this
   directory, in the shape `build_knowledge_base.py` expects (see any file
   here for the schema).

### Crops covered

| File | Crops |
|---|---|
| `niphm_rice.json` | Rice |
| `niphm_batch1.json` | Cotton, Wheat, Tomato, Onion, Mango |
| `niphm_batch2.json` (if present) | see file — a second extraction pass covering additional crops already represented in the pre-rebuild knowledge base |

Run `python cv/scripts/build_knowledge_base.py` any time a new
`niphm_*.json` file is added here — it picks up every file matching that
glob automatically.

## Supplementary entries (`supplementary_entries.json`)

A smaller set of entries aren't tied to one specific crop package:

- **Cross-crop pests** (aphids, whitefly, spider mite, leaf miner,
  leaf-eating beetle, grasshopper, locust) that appear across many crops.
  Their pesticide names/formulations/rates match real CIBRC-registered
  product labels and were cross-checked against the relevant sections of the
  crop-specific NIPHM packages above, but — unlike the crop-specific
  entries — they weren't extracted from one single downloaded PDF. Each
  entry's `sources` field says so explicitly rather than attributing them to
  a document they didn't come from.
- **Nutrient deficiencies** (N, P, K, Mg, Fe, Zn, Ca). These aren't pest/IPM
  topics at all — NIPHM packages don't cover soil fertility — so they're
  sourced to general ICAR Package-of-Practices / FAO plant-nutrition
  guidance instead, again stated plainly in the `sources` field.
- **Locust**: deliberately steers a farmer toward reporting a swarm to the
  government Locust Warning Organisation rather than presenting a per-farm
  chemical recommendation, since locust control in India is a coordinated
  government response, not an individual IPM decision.

## What's honestly estimated, not sourced

Three fields exist in the schema for UI convenience but aren't something any
IPM document reports, and are filled with general, clearly-non-authoritative
estimates rather than fabricated precision:

- `severity_level` — inferred from keywords in the symptom description
  (e.g. "national-significance", "epidemic") — a rough triage label, not a
  government classification.
- `expected_recovery_days` — a general estimate by pest/disease category
  (fungal/bacterial ≈ 14 days, viral ≈ 0 since there's no cure, insect/mite
  ≈ 10 days, nematode ≈ 21 days), not a number any source document states.
- `recovery_recommendations` — a generic, category-appropriate note, not
  crop-specific advice.

Everything else — scientific names, symptoms, cultural/biological control,
chemical control, dosages, and the general safety/waiting-period notes — is
either quoted/paraphrased from the cited government document or explicitly
labeled as general (not source-specific) guidance, per crop entry.
